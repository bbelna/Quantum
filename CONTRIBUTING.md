Version 0.1-alpha, March 2026  
Copyright © 2025-2026 The Quantum Software Project

---

Contributions, which come in the form of *pull requests* (PRs), of all kinds are
welcome. If you are new and interested in working on Quantum:

1. Browse the [Issues](https://github.com/The-Quantum-OS-Project/Quantum/issues) to find work that interests you. Use the "[Good First Issue](https://github.com/The-Quantum-OS-Project/Quantum/issues?q=is%3Aissue%20state%3Aopen%20label%3A%22Good%20First%20Issue%22)"
label to find easy wins.
2. Check the [Quantum Development](https://github.com/orgs/The-Quantum-OS-Project/projects/1) project to understand current priorities and
milestones.
3. Pick up an unassigned issue or open a new one if you identify missing work.
**Note PRs do not necessarily require a linked issue.** The only type
of PR that does require a linked issue is a PR establishing a new feature.
See Pull Requests for more details.
4. Create a branch, make focused changes, and open a PR.

There is no rigid contribution bureaucracy. Follow existing conventions, keep
changes scoped and readable, and favor clarity over cleverness. Discussion and
iteration are part of the process. Documentation regarding coding standards and
conventions is forthcoming and will be located in this wiki.

Even small contributions, including documentation improvements or cleanup
refactors, are valuable.

PRs do not *necessarily* require a linked issue. The only type of PR that
requires a linked issue is one that establishes a new feature.

**Why?** Issues are required for features in order to facilitate discussion,
scoping, and planning that will ensure the new feature aligns with Quantum's
goals and standards (and there are a lot of standards, especially undocumented
standards, as of now). Namely, it gives me (Brandon Belna, the project lead)
a chance to review the feature, its planned implementation, etc. and ensure that
it's done in a way that will be accepted so you don't waste time on an
implementation that needs a ton of changes.
